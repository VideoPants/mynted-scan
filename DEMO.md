# DEMO — recording script

1. Install the PWA on a phone (HTTPS or `next dev --experimental-https`).
2. Guided capture: checks turn green; burst fires.
3. Pick the card with manual search.
4. Show results: overlays/ratios, ceilings, borderline flags.
5. Capture the back.
6. Full-art / low confidence → manual adjust.
7. Switch to Arabic; confirm RTL (card not mirrored).
8. Save to history and create a share link.
9. Show `/embed/report/:slug` as it would appear on a listing.
10. Show ACCURACY.md tables.
